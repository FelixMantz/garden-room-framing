# Garden room app and master specification

## Required synchronisation

The app and the master specification describe the same build. Maintain both in the same task when a change affects dimensions, materials, openings, roof/wall/floor layers, cutting quantities, fixing schedules, or construction details.

**Master specification:** [Garden Room Design Specification - MASTER](https://docs.google.com/document/d/1ILhSBko2Po7cq2c5KZfn3nbhcgPIh1S5PD6NR_BnrPw/edit)

1. Read the current master document through the connected Google Drive/Docs tools before making a relevant change. Read the current app sources as well; do not rely on a remembered or exported copy.
2. Resolve differences using the owner's latest explicit decisions and confirmed as-built measurements. Do not silently substitute stale app values for confirmed spec values, or vice versa.
3. Change the affected app geometry, diagrams and schedules, and update the corresponding master-spec sections in the same task. Reconcile dependent dimensions, quantities, stock reservations and budget allocations.
4. Preserve historical purchase records when installed materials change. Distinguish ordered stock from the installed build.
5. Regenerate the technical PDF and run the relevant existing checks. Inspect affected PDF pages when drawing geometry or layout changes.
6. Read back the changed master-spec content and verify that it agrees with the app. Do not insert changelogs or update commentary into the master document unless requested.
7. If access to the master document is unavailable, complete the independent work and clearly state which synchronisation is outstanding. Never claim synchronisation without verifying both.

A source-code comment is a maintenance instruction, not an automatic synchronisation mechanism. Changes to code alone do not update the Google Doc.

Publishing follows the owner's instruction for the task.
